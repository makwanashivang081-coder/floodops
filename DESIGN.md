# FloodOps UI — serious municipal

Professional civic ops tool. Not a game, not a consumer lifestyle app.

## Direction
- Calm paper + ink surfaces, hairline structure
- Restrained teal rain accent, amber only for urgency signal
- No playful neumorphism, no pill candy, no oversized game CTAs
- Dense, scannable lists; selected row expands detail **inline below**

## Fonts
- Display: Syne (sparingly, titles)
- Body: IBM Plex Sans

## Do not
- Gamified badges clusters, soft clay toys, bounce-heavy motion
- Purple SaaS gradients, glassmorphism, emoji icon rows
